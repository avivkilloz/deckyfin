## What We Fixed This Session (June 2026)

### 1. Proton Version on "Add to Steam"
- **Problem:** `add_steam_shortcut` didn't accept or apply `proton_version`. Proton was only applied on "Update Steam".
- **Fix:** Added `proton_version: Optional[str] = None` param to backend `add_steam_shortcut`, calls `set_proton_version()` after creating shortcut.
- **Frontend:** `addSteamShortcut` callable signature updated with `proton_version?: string`. `handleAddToSteam` passes `protonVersion || undefined`.
- **Debugging:** Added `_debug()` logging to trace proton_version values at runtime.

### 2. Browse scans game root dir, not startDir
- **Problem:** Exe picker `handleOpenExePicker` used `startDir || game.name` as scan root. StartDir is the working directory, not the game's root folder.
- **Fix:** Changed scan root to `game.path || game.name`. The `game.path` field (set during auto-detection) points to the game's folder under `games_folder`.

### 3. Loading text removed from main menu
- **Problem:** `<p>Loading...</p>` rendered in GameLibrary during initial load.
- **Fix:** Removed the line entirely. Between mount and backend returning, just render an empty grid.

### 4. Restart Steam button state persists across sidebar opens
- **Problem:** Decky plugins remount on every sidebar open, resetting React `useState(false)` to false.
- **Fix:** Backend stores needs-restart flag at `<games_folder>/.deckyfin/needs_restart`. `get_needs_restart()` / `set_needs_restart()` endpoints. Frontend reads on mount via `useEffect` + `getNeedsRestart()`. `onNeedsRestart` also persists to backend.
- **Callable name conflict:** `setNeedsRestart` callable collided with `useState` setter → renamed state setter to `setNeedsRestartState`.

### 5. Folder browser in Settings page
- **Backend:** `list_subfolders(path: str)` lists non-hidden subdirectories. Catches `PermissionError` per-entry. Logs via `_debug()`.
- **Frontend:** Browse button next to games folder input opens a folder navigator starting at `/`. Shows subfolders, ".. (up)" to go up, "✓ Select This Folder" to confirm. Close with ✕ or Browse toggle.
- **Focus highlight fix:** All picker items (folder browser, exe picker, proton picker) MUST have `margin: "0 2px"` and `padding: "4px 10px"`. Container uses `padding: "2px 0"`. Without this, Decky's `is-focused` blue outline clips at top/bottom edges.

### 6. Save button feedback

- **Fix:** Inline feedback next to Save button — green ✅ or red ❌, auto-clears after 3s via `setTimeout`.

## Key Patterns & Pitfalls

- **Debug logging:** Use `_debug(f"method: var={val!r}")` in main.py → writes to `debug.log` in plugin dir at `/home/deck/homebrew/plugins/deckyfin/debug.log`.
- **PermissionError per-entry:** In `list_subfolders`, catch `PermissionError` inside the `iterdir()` loop, not at the outer level. One unreadable dir shouldn't kill the entire listing.
- **Focus highlight on picker items:** `margin: "0 2px"` on every `Focusable` in scrollable lists (exe picker, proton picker, folder browser items). Container `padding: "2px 0"`.
- **callable name collision:** When a `callable` name matches a `useState` setter, rename the state setter with `State` suffix (e.g., `setNeedsRestartState`).
- **Needs-restart must persist backend-side:** React state resets on sidebar remount. Use a flag file + backend endpoints.
- **Three path concepts:** `game.path` (scan root), `executable` (full exe path), `startDir` (working directory). Each is different.

## Architecture Notes (from previous session)

### App ID Calculation
Steam generates app IDs for non-Steam shortcuts via: `CRC32(exe + app_name) | APPID_CRC32_MASK`.
- `calc_shortcut_app_id()` in `steam_games.py` implements this
- `convert_appid_to_unsigned_32bit()` converts signed → unsigned
- `convert_appid_to_config_format()` converts to 64-bit for CompatToolMapping

### Two Types of App IDs
1. **`steam_app_id`** — manual Steam Store app ID. Used ONLY for dependency lookup via ProtonDB/WineDB. NOT used for Steam shortcut detection.
2. **`shortcut_app_id`** — the CRC32-generated app ID from shortcuts.vdf. Saved to config for prefix tracking. Detection is name-based only.

### Key Files
- `py_modules/steam_games.py` — VDF read/write, app_id calculation
- `src/components/GameDetail.tsx` — game detail view, action buttons, config persistence
- `src/components/GameLibrary.tsx` — library view, Steam detection, needs-restart button
- `src/components/SettingsPage.tsx` — settings with folder browser, API key, save feedback
- `main.py` — backend endpoints (add/update/remove Steam, list_subfolders, needs-restart state)
- `error-context-to-hermes.txt` — user drops errors here for me to debug
